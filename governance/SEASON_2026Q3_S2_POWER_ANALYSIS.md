# S2 Statistical Power Evidence

| 항목 | 결과 |
|---|---:|
| Target power | 0.8000 |
| Simulated achieved power | 0.5537 |
| Minimum detectable effect | 5.0000 |
| Required independent groups | 324 |
| S2 planned groups | 180 |
| Pilot paired groups | 35 |
| Simulations | 10,000 |

S2의 180개 독립 그룹 설계는 사전등록한 목표 검정력을 충족하지 못했다. alpha, MDE, target power,
weight 또는 판정 threshold를 사후 완화하지 않고 official split 작성 전에 S2를 중단한다. 동일한 여섯
영역을 54개씩 배치한 총 324개 설계는 계산상 power 0.8010을 제공한다.

이 파일은 aggregate-only evidence다. pilot group ID, prompt, response, 개별 case score는 포함하지 않는다.
